
# Stock Taking

Este proyecto ha sido creado para resolver una necesidad de un negocio local, con este proyecto, el usuario podrá registrar todos sus productos, y generar tickets para posteriormente darselos a su cliente. El proyecto tiene parte de gestión de inventario y una pequeña parte de generar ticket, así como hacer la impresión de los mismos.
## Objetivo del proyecto

Durante el desarrollo de este sistema de gestión de inventario con impresión de tickets, quiero aprender los siguientes conceptos:

⚙️ Estructura de un backend robusto con Laravel:

    Uso avanzado de Eloquent y relaciones complejas.

    Aplicación de filtros dinámicos y consultas eficientes.

🖨️ Impresión de tickets:

    Generación de tickets en PDF usando DOMPDF.

    Envío directo a impresoras térmicas mediante mike42/escpos-php.

📦 Gestión de inventario:

    Control de stock con entradas, salidas y movimientos históricos.

    Alertas automáticas por bajo stock o productos próximos a caducar.

🧾 Interfaz tipo punto de venta (POS):

    Creación de una experiencia rápida para registrar ventas.

    Búsqueda dinámica de productos y manejo eficiente del carrito.

📊 Reportes y estadísticas:

    Panel administrativo con métricas en tiempo real.

    Exportación de reportes diarios, semanales y mensuales.

📨 Notificaciones internas:

    Alertas para eventos clave (como productos agotados).

⏳ Manejo de colas y tareas en segundo plano:

    Uso de jobs y workers para impresión, envío de correos y procesamiento de datos.

🧪 Testing y buenas prácticas:

    Creación de tests automatizados para asegurar la estabilidad del sistema.

    Uso de migraciones, seeders y control de versiones en base de datos.
